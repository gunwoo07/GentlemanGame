# Gentleman Game

Pygame으로 만든 타워 디펜스 게임

---

## 실행 방법

### 1. 실행 방법
이 파일이 있는 디렉토리에서 다음 명령어 입력
```bash
python main.py
```

### 2. 기본 조작법
- **웨이브 시작**: `Space` 바
- **타워 선택 및 배치**: 하단 메뉴에서 타워 아이콘 클릭 후 맵에 **좌클릭**
- **타워 병합**: 한 타워를 좌클릭 후 같은 종류, 같은 레벨 타워를 좌클릭하면 두번째 클릭한 타워로 병합
- **타워 선택 취소**: **우클릭**
- **타워 강화/매각**: 배치된 타워를 클릭한 후 하단에 나타나는 버튼 이용
- **배속 조절**: `2` 키 (1배속 / 2배속 전환)
- **일시정지**: `F` 키
- **타이틀 화면으로 이동**: `ESC` 키 (현재 진행 상황이 자동 저장됩니다)

## 새롭게 추가한 기능

1. **개별 최단 경로 이동**
   - 각각의 적이 최단 경로로 이동

2. **최단 경로 미리보기**
   - 타워를 배치하기 전, 맵 위에 마우스 커서를 올리면 해당 위치에 타워를 설치했을 때 변화할 새로운 최단 경로를 옅은 하늘색 선으로 미리 보여줌

3. **2배속**
   - 게임 진행 중 지루하면 속도를 조절할 수 있음
